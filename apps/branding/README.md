# Meshmellow branding

The product name is **Meshmellow**, styled `meshmellow` in the wordmark.

The cake logo is the image supplied by the user:
[Minecraft Wiki — Cake JE4](https://minecraft.wiki/images/Cake_JE4.png?7c59e).
`meshmellow.png` is the original downloaded PNG. Launcher artwork places the same
image on a neutral background; `build-icon.swift` reproduces the iOS icon.

The native display names, app headers, launcher icons, web title and favicon use
Meshmellow. Existing bundle/package identifiers, Bonjour service types, enrollment
protocols, private storage locations and command compatibility remain stable so
installed apps update in place and keep their trusted identities and preferences.
