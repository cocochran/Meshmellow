Opening, 20 seconds: We are exploring a shared-memory-budget problem across separate devices. The goal is a model that needs pooled memory. Two-device execution is demonstrated; a model requiring that pooled capacity is still pending.

The problem

The model needs more room.

Model weights

The learned parameters must fit somewhere.

Conversation state

Context, KV or recurrent state, and runtime scratch need room too.

Contribution budgets

A device contributes an agreed amount, leaving room for its owner.

More devices add communication. Distributed inference can be slower.

30 seconds: Installed RAM is not a contribution budget. We explicitly account for reservations and context-related memory in planning. Current budgets are estimates, not enforced runtime caps.
